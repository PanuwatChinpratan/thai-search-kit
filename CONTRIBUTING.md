# Contributing

```text
feature/* ──PR──> develop ──release PR──> main
fix/*     ──PR──> develop
docs/*    ──PR──> develop
```

1. Create a focused branch from the latest `develop`.
2. Add tests and benchmark cases for ranking changes.
3. Run every command listed in `AGENTS.md`.
4. Open a pull request with a Conventional Commit title.

Please keep the core dependency-free and the playground intentionally small.
